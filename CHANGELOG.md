# Changelog

All notable changes to Carousel Story Engine are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-24

### Added

- Portable AI skill for evidence-led Instagram and LinkedIn carousels.
- Editorial framing, hook comparison, narrative progression, slide writing,
  skeptic review, compression and visual direction.
- Claim ledger separating reported facts, observations, theses, hypotheticals and
  recommendations.
- Production briefs, structured JSON and optional rendered output guidance.
- Brand-identity safeguards and explicit non-imitation rules.
- Six-case evaluation suite, public quality rubric, regression results and a
  complete consulting carousel example.
- Installation instructions for Codex, Claude Code, Cursor and other agents.

### Validation

- Skill metadata and structure validated with the Codex skill validator.
- Repository links, assets, examples and references checked locally.
- No runtime service, bundled credential or required API key.
